# Game3 — Tampermonkey

[Скачать ZIP для Windows 10](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/arena/27e65b2f-game-3/downloads/Game3-Windows10-x64.zip). Внутри **один файл** — `Setup-Game3.bat`. Распакуйте и запустите его.

Батник проверяет реестр Windows и типовые папки установки Google Chrome, Edge, Firefox, Brave, Vivaldi, Яндекс Браузера, Opera и Opera GX. Он не читает профили браузеров. Редкие портативные установки и нестандартные пути могут не обнаружиться. Окна открываются в текущем или обычном профиле браузера; устанавливайте расширение в том профиле, в котором будете играть.

Для каждого найденного браузера выберите:

- **S — настройка.** Если Tampermonkey ещё нет, батник откроет его страницу в магазине. После установки он откроет менеджер расширений: там включите Tampermonkey, разрешите ему доступ к `yandex.ru` и включите **Allow User Scripts / Разрешить пользовательские скрипты**, если такой переключатель есть. Для старых Chromium, где он отсутствует, проверьте режим разработчика на странице расширений. Затем батник откроет скрипт — подтвердите установку в Tampermonkey.
- **U — разовая проверка.** Батник один раз откроет опубликованный `.user.js`. Tampermonkey сравнит его с установленным скриптом: подтвердите **Update**, если предлагается обновление. Если предлагается только **Reinstall**, переустановка не нужна.
- **K — пропустить** этот браузер.

Батник не устанавливает разрешения и расширения за пользователя, не создаёт автозапуск и не оставляет процессов. Если он найдёт задачу входа **Game3 Userscript Update** от предыдущей версии, он предложит её удалить. Фоновая проверка внутри Tampermonkey не настраивается этим батником и зависит от собственных настроек расширения.

## Прямая установка и проверка

[Открыть `games-redirect.user.js` в Tampermonkey](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/arena/27e65b2f-game-3/games-redirect.user.js). Если браузер только скачал файл, импортируйте его через **Tampermonkey → Панель управления → Утилиты → Импорт из файла**. В панели Tampermonkey скрипт **Yandex Games Redirect** должен быть включён.

Откройте `https://yandex.ru/games/`: вкладка должна перейти на «Тихий отскок». После открытия игры скрипт не вмешивается в рекламные переходы внутри игровой страницы.
