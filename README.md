# Game3 Userscript Updater

`Game3-Updater-win64.exe` — переносимая программа для 64-битной Windows 10. Не нужны Git, Python, права администратора или установщик. Положите её в папку, в которую можно писать, и запустите вручную.

Программа запрашивает `games-redirect.user.js` из публичной ветки `arena/27e65b2f-game-3` репозитория `VolodyKira/game_3` через GitHub API по HTTPS. Если файл отсутствует или отличается, программа записывает новую копию рядом с `.exe`. При совпадении ничего не меняет, а при ошибке загрузки оставляет существующий файл на месте.

После загрузки: **Tampermonkey → Панель управления → Утилиты → Импорт из файла**. Программа не запускает скачанный код, не обновляет сам `.exe`, не меняет настройки браузера и не добавляет автозапуск. Обновления берутся из указанной ветки, поэтому перед импортом можно проверить скачанный скрипт как текст.

## Сборка

Из корня проекта, с Zig (нужен только тому, кто собирает):

```sh
mkdir -p artifacts
zig cc -target x86_64-windows-gnu -std=c11 -Wall -Wextra -Werror -Os -s updater/main.c -lwinhttp -o artifacts/Game3-Updater-win64.exe
```
