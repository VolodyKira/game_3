# Game3 — локальный каталог

[Скачать ZIP для Windows](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/arena/27e65b2f-game-3/downloads/Game3-Windows10-x64.zip). Распакуйте файлы вместе:

1. Один раз запустите `Setup-Game3.bat` или [установите скрипт напрямую](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/arena/27e65b2f-game-3/games-redirect.user.js) в Tampermonkey. Для версии 2.0.0 подтвердите доступ скрипта к `127.0.0.1` — это проверка, что локальная страница запущена.
2. Запустите `Start-Game3-Local.bat`. Пока его окно открыто, `game3-catalogue.html` доступен по адресу `http://127.0.0.1:8765/game3-catalogue.html`. Сервер доступен только с этого ПК. Ничего не добавляется в автозапуск; для остановки закройте окно. HTML можно открыть напрямую для просмотра, но для перенаправления нужен локальный адрес: браузеры блокируют переходы с HTTPS на `file://`.
3. В браузере с включённым Tampermonkey откройте `https://yandex.ru/games/`. Главная, каталог, поиск и известные разделы откроются в соответствующих вкладках локальной копии. Другие игры открывают локальный каталог. Сама игра «Тихий отскок» (`597546`) открывается только на официальном сайте, в том числе по ссылкам вида `/games/#app=597546`.

Если локальный сервер не запущен, скрипт оставляет официальную страницу на месте. Он не вмешивается в известные рекламные переходы и неизвестные служебные адреса, а после открытия игры не реагирует на изменения адреса внутри игрового документа.

## Если скрипт не запускается

В Chrome или Edge включите **Разрешить пользовательские скрипты** и дайте Tampermonkey доступ к `yandex.ru`. В старых Chromium без такого переключателя проверьте режим разработчика. Скрипт **Yandex Games Redirect** должен быть включён; если ссылка скачала файл, импортируйте его через **Tampermonkey → Панель управления → Утилиты → Импорт из файла**. Для обновления используется та же ссылка, что и для установки.

`Setup-Game3.bat` ищет поддерживаемые браузеры и открывает магазин, менеджер расширений или ссылку обновления по выбору. Он не меняет разрешения браузера и не создаёт задач; старую задачу от прежнего комплекта может удалить с подтверждением.
