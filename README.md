# Game3 — локальный каталог без сервера

[Скачать ZIP для Windows](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/main/downloads/Game3-Windows10-x64.zip). Внутри два файла: `Setup-Game3.bat` и `game3-catalogue.html`. Распакуйте их вместе в постоянную папку.

## Настройка один раз

1. Запустите `Setup-Game3.bat` или [установите/обновите скрипт напрямую](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/main/games-redirect.user.js) в Tampermonkey. Для автоматического открытия локального файла используйте Chrome, Edge или другой Chromium с поддержкой доступа к `file://`. Firefox для этого режима не поддерживается.
2. В карточке Tampermonkey включите **Разрешить доступ к URL файлов** (*Allow access to file URLs*) и, если есть этот переключатель, **Разрешить пользовательские скрипты** (*Allow User Scripts*). Убедитесь, что у Tampermonkey разрешён доступ к `yandex.ru`. Если браузер не запускает Tampermonkey на локальных файлах при ограниченном доступе к сайтам, можно оставить файл для ручного открытия вместо расширения этого разрешения.
3. Откройте `game3-catalogue.html` в этом же браузере и профиле один раз после установки. Скрипт запомнит адрес файла в хранилище Tampermonkey. Если файл перемещён, откройте его из новой папки ещё раз.

## Как это работает

Когда открывается официальный адрес главной, каталога, категории или поиска, Tampermonkey открывает сохранённый HTML в **новой вкладке** с соответствующим разделом. Официальная вкладка не закрывается: браузер не позволяет обычной HTTPS-странице перенаправить текущую вкладку на `file://`. Если адрес файла не зарегистрирован, ничего не происходит; HTML всегда можно открыть вручную.

Ссылки на «Тихий отскок» (`597546`) остаются официальными, в том числе `/games/#app=597546`. Рекламные и неизвестные служебные адреса не перехватываются. После открытия игры скрипт не вмешивается в изменения адреса внутри её документа.

**Локального сервера, автозапуска и открытого CMD не нужно.** `Setup-Game3.bat` нужен только для первоначальной настройки. Он не меняет разрешения браузера и может с подтверждением удалить старую задачу входа, если она осталась от прежнего комплекта.
