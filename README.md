# Game3 — локальный каталог

[Скачать ZIP для Windows 10 x64](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/main/downloads/Game3-Windows10-x64.zip). Распакуйте весь архив и один раз запустите `Setup-Game3.bat`.

1. Ответьте **Y** на вопрос о запуске локального каталога при входе в Windows. Установщик скопирует сервер и HTML в `%LOCALAPPDATA%\Game3LocalCatalogue`, зарегистрирует задачу **Game3 Local Catalogue** для текущего пользователя и запустит её сразу. Права администратора не требуются, если политика Windows разрешает создавать обычные пользовательские задачи.
2. Установите или [обновите скрипт Tampermonkey](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/main/games-redirect.user.js) до **3.0.0**. Если Tampermonkey спросит доступ к `127.0.0.1`, разрешите его. В Chrome и Edge включите **Разрешить пользовательские скрипты** и предоставьте Tampermonkey доступ к `yandex.ru`. Доступ к `file://` больше не нужен.
3. Откройте `https://yandex.ru/games/`. Если сервер запущен, каталог откроется в той же вкладке. Чтобы проверить сервер отдельно, откройте [локальную страницу](http://127.0.0.1:8765/game3-catalogue.html).

Сервер запускается при входе в Windows **без окна CMD** и доступен только на этом компьютере, на `127.0.0.1:8765`. Он отдаёт только HTML и ответ проверки доступности. При каждом запуске сервер один раз проверяет `game3-catalogue.html` в публичной ветке `main` по HTTPS. Он сразу открывает сохранённую страницу и заменяет её, только если GitHub прислал отличающуюся совместимую версию. При ошибке сети или записи остаётся прежний файл. Если сервер выключен, официальный каталог открывается как обычно. Ссылки на «Тихий отскок» (`597546`), известные рекламные и служебные адреса, а также переходы внутри уже запущенной игры остаются без редиректа.

Автообновление касается только HTML: `.exe`, батник и настройки браузера сервер не обновляет. Политика безопасности, зашитая в сервер, разрешает только известный встроенный скрипт каталога. Текст и стили можно обновлять без пересборки; при изменении встроенного JavaScript нужно пересобрать сервер с его новым SHA-256. Для перехода со старой версии скачайте новый ZIP и запустите `Setup-Game3.bat` ещё раз. При обновлении батник останавливает задачу **Game3 Local Catalogue** и ждёт завершения установленного процесса `Game3-Local-Server.exe`, затем копирует файлы, включает задачу и запускает её снова. Одноимённые процессы из других папок он не трогает.

**Отключить и остановить:** запустите `Setup-Game3.bat /remove-server` или найдите **Game3 Local Catalogue** в Планировщике заданий, завершите и удалите задачу. Локальные файлы не удаляются автоматически. Для диагностики: результат `0x2` означает, что сервер не смог прочитать `game3-catalogue.html`, `0x3` — не удалось открыть порт или запустить сеть.

## Сборка сервера

Zig нужен только для сборки, не для запуска на Windows:

```sh
zig cc -target x86_64-windows-gnu -Wl,--subsystem,windows -std=c11 -Wall -Wextra -Werror -Os -s server/main.c -lws2_32 -lwinhttp -o Game3-Local-Server.exe
```

В архив должны входить `Setup-Game3.bat` (CRLF), `Game3-Local-Server.exe` и `game3-catalogue.html`.
