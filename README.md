# Game3 Userscript Updater

## Tampermonkey: установка и проверка

1. Установите Tampermonkey из магазина расширений браузера. В актуальном Chrome или Edge откройте карточку расширения и включите **Разрешить пользовательские скрипты** (*Allow User Scripts*). Если в старой версии браузера этого переключателя нет, включите **Режим разработчика** на странице расширений. Для Tampermonkey разрешите доступ к сайту `yandex.ru`.
2. Откройте [файл установки](https://raw.githubusercontent.com/VolodyKira/game_3/refs/heads/arena/27e65b2f-game-3/games-redirect.user.js) и нажмите **Установить**. Если браузер просто показывает или сохраняет файл, откройте **Tampermonkey → Панель управления → Утилиты → Импорт из файла** и импортируйте `games-redirect.user.js` вручную. В списке скрипт **Yandex Games Redirect** должен быть включён. Если установлена старая копия с тем же именем, обновите её, не оставляйте два экземпляра.
3. В обычной вкладке откройте `https://yandex.ru/games/`. Адрес должен смениться на `https://yandex.ru/games/app/tikhii-otskok-597546`. Если не сменился, проверьте, что скрипт отображается в меню Tampermonkey на этой вкладке. Для диагностики нужны точный URL, браузер и статус скрипта в меню.

С версии 1.2.0 скрипт перенаправляет только каталог и страницы других игр. После открытия «Тихого отскока» он не вмешивается в рекламу, оверлеи и изменения адреса внутри игровой страницы.

Tampermonkey сам обновляет **установленный** скрипт по `@updateURL` и `@downloadURL`, если включена проверка обновлений и в репозитории повышен `@version`. Windows-программа скачивает только копию **на диск**, не обновляет расширение и не запускает скачанный код.

## Windows 10 x64: настройка одним батником

Распакуйте весь ZIP и дважды щёлкните `Setup-Game3.bat`. Команды PowerShell вводить не нужно. Батник копирует `Game3-Updater-win64.exe` из архива в `%LOCALAPPDATA%\Game3Updater`, регистрирует обычную задачу **Game3 Userscript Update** для текущего пользователя, запускает первую проверку и открывает ссылку установки скрипта в браузере по умолчанию. Права администратора и установка дополнительных программ для проверки на Windows не нужны. Для браузерной части нужен Tampermonkey; его разрешения и подтверждение установки остаются под контролем пользователя.

После входа в Windows задача стартует один раз с задержкой 45 секунд, проверяет файл по HTTPS, заменяет локальную копию только при отличии и завершается. При ошибке загрузки старая копия остаётся. «Последний результат» задачи: `0x0` — успешно (в том числе если обновлений нет), `0x1` — ошибка. Для подробностей можно запустить установленный `.exe` двойным щелчком.

Отключить автопроверку: удалите задачу в Планировщике или запустите `Setup-Game3.bat /remove`. Это не удаляет локальный файл и не меняет Tampermonkey. Если правила Windows запрещают регистрацию, батник показывает ошибку вместо обхода политики.

## Сборка `.exe`

Для сборки нужен Zig, но на компьютере пользователя он не нужен:

```sh
mkdir -p artifacts
zig cc -target x86_64-windows-gnu -Wl,--subsystem,windows -std=c11 -Wall -Wextra -Werror -Os -s updater/main.c -lwinhttp -luser32 -o artifacts/Game3-Updater-win64.exe
```
